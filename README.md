# 투자 대시보드 — 분할매수 플래너

티커(QQQ, AAPL, ^GSPC)나 한국 종목코드(005930)를 넣으면 전체 기간 일봉 수정종가를 자동으로 불러와
52주 최고가 대비 과거 하락 사이클을 세고, 단계별 매수가·비중·평균단가를 계산합니다.
결과는 1080×1350 PNG로 저장할 수 있습니다.

- `index.html` — 화면 전체 (빌드 과정 없음)
- `api/search.js` — 종목 검색 (네이버 증권 자동완성 + Yahoo 검색)
- `supabase/functions/planner-sync` — 기기 간 동기화, 텔레그램 연결, 낙폭 데이터 조회
- `supabase/functions/price-alerts` — 장중 5분마다 실시간 알림, 장 마감 종가 알림과 낙폭 리포트 (pg_cron이 호출)
- `api/prices.js` — Vercel 서버리스 함수. Yahoo Finance에서 가격을 받아 옵니다 (실패 시 미국 종목은 Stooq로 재시도).
- 바로가기 링크: `https://<내-주소>.vercel.app/?t=QQQ`

## 배포 (Vercel, 무료)
1. vercel.com → Add New… → Project → 이 GitHub 저장소 Import
2. Framework Preset: **Other**, 빌드 설정은 비워 둔 채 Deploy
3. 이후 저장소에 push하면 자동으로 다시 배포됩니다.

## 텔레그램 알림
- 매수 계획에서 '이 계획으로 진행하기'를 누른 종목만 알림 대상입니다.
- 장중(미국 정규장, 국장) 5분마다 실시간 가격 확인 → 단계 가격 도달 시 알림. 같은 단계는 7일에 한 번.
- 장 마감 뒤(한국시간 07:10 미국장, 16:10 국장) 종가 알림 + 즐겨찾기 종목 낙폭 리포트.
- 직전 매수 후 10거래일 동안은 다음 매수 단계 알림을 보류합니다.
- 알림마다 `✅ 체결` 버튼이 붙습니다. 누르면 계획 가격·수량으로 매매 기록에 들어가고(1분마다 pg_cron `planner-tg-updates`가 처리),
  사이트는 화면으로 돌아올 때와 열어둔 동안 90초마다 받아와 보유 현황에 반영합니다.

## 보유 현황과 계획
- **📌 계획 진행 중**: '이 계획으로 진행하기'를 누른 종목. 매수 n/5단계와 할 일 수를 보여줍니다. 보유 현황은 그래프 없이 한 화면에 들어오는 표 (휴대폰은 만원 단위).
- **보유만**: 실제 보유분만 불러온 종목. '계획 세우기'로 계획을 시작할 수 있습니다.
- 사이트에서 차례가 온 단계의 `✅ 체결 기록`을 누르거나 텔레그램 ✅를 누르면 수량·평단·손익이 자동으로 바뀝니다.
- 투자금은 '이 계획에 새로 넣을 현금'입니다. 불러온 기존 보유분은 남은 현금 계산에서 빠집니다.

## 계산 방식
- 하락 사이클: 상장일부터, 종가가 52주 최고가(252거래일 종가 최고)보다 최소 낙폭(기본 5%) 이상 떨어진 날 시작,
  그 고점을 다시 넘은 날 완료. (완료가 10번 미만이면 52주 신고가 경신도 완료로 봄) 진행 중인 하락은 제외.
- 1~4단계: 완료된 사이클 중 상위 1/2 · 1/4 · 1/8 · 1/16이 도달한 깊이, 5단계: 가장 깊었던 하락.
- 비중: 기본 30·35·20·10·5 (채널 방식). 도달 횟수 비례 / 균등 / 깊을수록 크게도 선택 가능.
- 시작 단계: 1~4단계 중 선택. 앞 단계는 건너뛰고 그 비중을 남은 단계에 같은 비율로 나눔 (예: 3단계부터 → 57·29·14). 레버리지 종목은 처음 열 때 3단계로 시작.
- 이미 지난 단계는 지금 가격 기준으로 수량을 계산하고, 한 번에 한 단계씩 10거래일 간격으로 산다.
- 가격은 Yahoo Finance 일봉 수정종가 (period1=0~현재; range=max는 월봉으로 내려와서 쓰지 않음).

투자 권유가 아닌 참고용 계산입니다.
